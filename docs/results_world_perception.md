# Live 3D world — measured perception

Generated by `scripts/calibrate_world_appearance.py` on held-out renders of the
live world (random poses in every camera's zone, and fresh passes through the
entrance gate — never the enrollment views). Detector: `yolo11s.pt`.

| Measure | Value |
|---|---|
| Person detection recall, inside each camera's own zone (single frame, conf ≥ 0.25) | 74% overall; per camera 0: 73%, 1: 80%, 2: 75%, 3: 67% |
| Floor localisation error (foot point → calibrated homography) | median 0.181 m, 90th pct 0.365 m (n = 189) |
| Cross-camera appearance, same vs different person (score = similarity × quality) | AUC 0.9965; medians 0.899 vs 0.53 |
| → resolver match threshold (Youden J) | **0.7019** (TPR 97%, FPR 0%) |
| Gate verification (registry, 3 frames per decision, threshold 0.8, margin 0.06) | 15/15 correct accepts, **0 false accepts**, 0 rejected (the person simply keeps being checked) |
| Recognition by every camera (4 frames, threshold 0.8, margin 0.12) | 41/41 correct, **0 false**, 0 abstained; genuine median 0.911, best impostor 0.628 |
| Gate scores | genuine median 0.989 (10th pct 0.984); best impostor 0.647 |

Single-frame recall understates what a node achieves: ByteTrack carries a
person across frames where the detector's confidence dips, and a claim is
made every frame the track is alive.

The appearance signature is a hand-crafted clothing-colour descriptor
(`starling_perception.appearance`), chosen because the four employees'
uniforms differ by colour; it is not a general re-identification model.
