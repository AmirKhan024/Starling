# Live 3D world demo — automated review

Generated by `scripts/review_world_demo.py` against the real running system (world server, camera rig,
four camera nodes running YOLO + tracking + appearance + homography on rendered frames, dashboard).

| Moment | Verdict | What was checked |
|---|---|---|
| 1_checkin | **PASS** | Each of the four employees is verified at the entrance gate from the pixels and named on the manager view. |
| 2_tracking | **FAIL** | All four employees stay accounted for (in view, or out of view with a reason); believed positions track the truth. |
| 3_deadzone | **PASS** | While she is hidden, healthy cameras' attested absence keeps her search area inside the aisles; she is re-acquired as the SAME named identity. |
| 4_lens | **PASS** | The node notices the covered lens from its own pixels and stops vouching for its zone (silence is not evidence); it resumes when cleared. |
| 5_partition | **PASS** | Both halves keep tracking while cut off; after healing, anti-entropy brings every replica to the same claim set. |
| 6_lie | **PASS** | Peers catch physically implausible claims; only the liar's reputation falls. |
| 7_break | **FAIL** | Leaving through the staff door is recognised as 'left'; coming back, the employee is verified again at the gate. |
| 8_query | **PASS** | A safety query is answered (confirmed vs inferred); a productivity query and an unknown person are refused with reasons. |
| 9_every_camera | **PASS** | Each camera node, asked directly, resolves its OWN replica over the same window; all four return the identical answer fingerprint (C1: same claims, same deterministic answer). |
| 10_intruder | **PASS** | A person who is not enrolled and never passes the gate is tracked as an unknown identity, raises a manager alert, and is answered for in plain English. |
| 11_area_query | **PASS** | An area question is answered with its evidence (seen / attested clear / silent); the camera-less aisles are never declared empty. |
| 12_rollcall | **PASS** | The roll call counts exactly the people really inside (employees, hidden ones, unknown people). |
| 14_recognition | **PASS** | Every camera (not only the gate camera) recognises enrolled employees, so a name lost to a track break is restored by whichever camera sees the person next; nobody is left 'missing'. |
| 13_failures | **PASS** | Killing the central server blinds it entirely while Starling keeps tracking; powering off one camera loses only that camera (three still answer); powered back on, it catches up and every replica converges. |
